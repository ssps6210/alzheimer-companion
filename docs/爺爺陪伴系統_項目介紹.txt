  爺爺語音陪伴系統　Elder Voice Companion
  ——　用家人的聲音，陪伴失智長者
════════════════════════════════════════════════════════════

【這是什麼】
一套給失智（Alzheimer's）長者用的語音 AI 陪伴系統。
長輩只要在平板上「按住按鈕說話」，系統就會用「家人的聲音」溫柔地
回應他——像孫子、像兒女陪在身邊。

目標不是做一個很聰明的 AI，而是做一個「永遠耐心、永遠都在、
聽起來像親人」的陪伴者。對失智長者來說，被愛與被陪伴，比聰明重要。


【為什麼做這個 / 為什麼開源】
失智長者最大的痛苦之一是孤單、混亂與重複的不安。家人無法 24 小時
在身邊，市面上的產品要嘛冷冰冰、要嘛不是家人的聲音、要嘛把長輩的
私密對話傳上雲端。

這個項目決定「開源」，因為：
  • 它對人類有益——高齡化社會人人都會用到。
  • 照護脆弱使用者的技術，本來就該透明、可被檢視，而不是黑盒。



【核心理念 / 與其他項目的差異】
掃過 GitHub / HuggingFace 上眾多語音陪伴項目後，沒有任何一個同時做到：
  ① 家人的多人聲音克隆（孫子、爸媽、弟弟……可切換）
  ② 失智照護的安全護欄（不糾正、不催促、會通報家人）
  ③ 為長者設計的極簡介面（一顆大按鈕，不需要學）

這三者的交集，就是本項目的價值與護城河。

特別堅持：**不放虛擬人臉 / Avatar**。
會動會說話的合成臉對 90 歲失智長者是驚嚇來源（尤其半夜起床、意識混亂時）。
取而代之，閒置畫面用「長輩自己的舊照片」慢速輪播——這是失智照護中
有實證的「懷舊療法」，能安撫情緒。


【系統架構】
  ┌─ 平板（Chrome，HTTPS）──────────────────┐
  │   按住說話 → 錄音 → 送出 / 接收音訊播放      │
  └──────────────────┬───────────────────────┘
                     │ HTTPS tunnel
  ┌─ PC（Windows + RTX 4060）────────────────┐
  │  FastAPI 伺服器（:8080）                    │
  │   1. faster-whisper　→ 語音轉文字（STT，本地）│
  │   2. 固定句快取　→ 命中常用語就秒回（跳過下面）│
  │   3. MiMo V2.5 API　→ 產生溫暖回覆（大腦）    │
  │   4. CosyVoice3　→ 用家人聲音合成（克隆 TTS）  │
  │      失敗時自動退　→ edge-tts（通用男聲）      │
  └──────────────────┬───────────────────────┘
                     │ localhost
  ┌─ WSL2（同一台 PC）───────────────────────┐
  │  CosyVoice3 TTS API（:50000）　聲音克隆引擎  │
  └──────────────────────────────────────────┘


【一次對話的流程】
  爺爺說話
    → Whisper 轉文字
    → 是常用固定句嗎？
         是 → 直接播放預錄好的家人聲音（零延遲、不靠網路）
         否 → MiMo 產生回覆 → CosyVoice 用家人聲音念出來 → 播放


【主要功能】
  ● 按住說話　　　　長者唯一要學的操作：按著講、放開送出
  ● 家人聲音克隆　　錄一段家人的聲音，AI 就用那個聲音說話
  ● 固定句快取　　　常見問答（吃藥、吃飯、想家、害怕…）預錄家人真聲，
  　　　　　　　　　命中即秒回，最溫暖也最可靠
  ● 多人陪伴（規劃）每位家人 = 一組「聲音 + 人設」，可切換輪流陪伴
  ● 舊照片畫面（規劃）閒置時慢速播放長輩的老照片（懷舊療法）
  ● 夜間模式（規劃）半夜自動轉暗、暖色，避免刺眼與驚嚇
  ● 設定檔驅動　　　所有設定集中在 conf.yaml，換模型/換聲音不用改程式


【技術選型重點】
  • STT：faster-whisper（本地、支援中文）
  • LLM：小米 MiMo V2.5（OpenAI 相容 API；關閉 reasoning 以求快又省）
  • TTS：CosyVoice3 零樣本聲音克隆（不需逐字稿，方便隨時換家人聲音）
  • Fallback：edge-tts，確保 CosyVoice 故障時仍「聽得到」（對失智者，
    沒聲音 ≈ 壞掉）
  • 隱私：API key 只放環境變數，不進程式碼/版本庫
