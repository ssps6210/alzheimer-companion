# 安裝指南（手把手）· Install Guide

> 這份寫給「**會用電腦、但不是工程師**」的人。照著做就行，卡住看最後的〈常見問題〉。
> 需要一台 Windows 電腦。整個過程約 30–60 分鐘（多半在等下載）。

---

## 〇、先確認電腦跑得動（配置需求）

| | 最低（能跑） | 建議（順、穩） |
|---|---|---|
| **顯卡 GPU** | NVIDIA **8GB VRAM**（RTX 3060 / 4060 / 2080…） | NVIDIA **12GB+**（3060 12G / 4070 / 2080 Ti） |
| **記憶體 RAM** | 8 GB | 16 GB+ |
| **硬碟可用空間** | **30 GB** | **50 GB+ SSD** |
| **作業系統** | Windows 10 (2004+) / 11 | Windows 11 |

> **8GB 剛好夠、偶爾會卡；12GB 以上順很多。**
>
> **沒有 NVIDIA 顯卡也能用。** 有 CPU 版：家人的聲音一樣是克隆的、一樣完全留在你的電腦，只是慢一點，而且**連 WSL 都不用裝**。下面凡是寫 `install.ps1` 的地方改成 `install_cpu.ps1`、`一鍵啟動.bat` 改成 `一鍵啟動_CPU版.bat`，並且可以跳過步驟 2️⃣（裝 WSL）。

---

## 一、先準備三樣東西（各做一次）

### 1️⃣ 裝 Python
到 <https://www.python.org/downloads/> 下載 **Python 3.10 以上**，安裝時**務必勾選最下面的「Add python.exe to PATH」**。
> ⚠️ 忘了勾這個，之後會出現「找不到 python」。忘了的話重裝一次、記得勾。

### 2️⃣ 裝 WSL（Windows 裡的 Linux，語音克隆要用它）—— 只有顯卡版需要
> CPU 版可以直接跳過這步。
1. 開始選單搜尋「**PowerShell**」→ 右鍵「**以系統管理員身分執行**」
2. 貼上這行、按 Enter：
   ```
   wsl --install -d Ubuntu-22.04
   ```
3. 裝完會要你**重開機**。重開後可能請你設一個 Linux 使用者名稱/密碼 —— 隨便設、記起來就好。

### 3️⃣ 申請免費 NVIDIA 金鑰（給 AI 大腦用）
到 <https://build.nvidia.com> 註冊/登入 → 隨便點一個 Nemotron 模型 → 右上「**Get API Key**」→ 複製那串 `nvapi-...`（等一下要貼）。

---

## 二、安裝（跑一次就好）

### 1️⃣ 下載專案
這個 GitHub 頁面右上綠色「**Code**」→「**Download ZIP**」→ 解壓縮到你喜歡的位置（例如 `D:\alzheimer-companion`）。
> 會用 git 的人：`git clone` 也行。放**哪個資料夾都可以**，腳本會自動定位。

### 2️⃣ 在專案資料夾裡開 PowerShell
打開剛解壓的資料夾 → 在**檔案總管上方的網址列**點一下、打 `powershell` 按 Enter → 會在這個資料夾開啟 PowerShell。

### 3️⃣ 跑安裝
貼上、按 Enter：
```
powershell -ExecutionPolicy Bypass -File install.ps1
```
它會自動：檢查環境 → 裝 Windows 依賴 → 裝 WSL 語音環境（**會下載好幾 GB，請耐心，約 20–40 分鐘**）→ 複製設定檔。

### 4️⃣ 填金鑰
用記事本打開資料夾裡的 `.env`，把 `nvapi-你的金鑰填這裡` 換成你剛複製的那串，**存檔**。

### 5️⃣ 啟動
雙擊 **`一鍵啟動.bat`** → 等它跑完（首次要載模型，約 1–2 分鐘）→ 會自動開兩個網頁。

✅ 完成！長輩的畫面 = <http://localhost:8080/>。

### 6️⃣ 換語言（選用）
打開 `conf.yaml`，把 `language:` 改成 `en`（English）或 `zh-CN`（简体）。介面、語音辨識與合成、照護護欄、人設會一起換。改完重啟生效。

---

## 三、設定家人的聲音（重要）

repo 裡**不含任何人的聲音**，要你自己放：
1. 開 <http://localhost:8080/setup>（雙擊「一鍵啟動」時會自動開）
2. 找「**① 🎙 設定陪伴聲音**」→ 上傳一段**清楚、安靜、10–30 秒**的家人聲音（wav / mp3 / m4a）
3. 錄音的**最開頭**要由本人親口唸出同意聲明（管理台上會顯示那一句）。這是刻意設計的：
   同意句就在同一段錄音裡，代表「這把聲音的本人」確實同意；聽不到就不會設定。
4. 按「**設為陪伴聲音**」→ 馬上生效

## 四、讓長輩在平板上用

**最簡單：裝 App**

1. 平板開 [Releases](https://github.com/ssps6210/alzheimer-companion/releases) 下載 `elder-companion.apk`
2. 允許「安裝未知來源」→ 安裝
3. 打開 App：同一個 WiFi 的話它會自己找到你的電腦；否則掃家人管理台上的 QR，或按貼上

App 會自己處理麥克風權限，不用做任何設定。

**或者用瀏覽器**（不裝 App）：平板 Chrome 開 `http://<你電腦的IP>:8080`（IP 在啟動視窗會顯示）。
純 http 下要讓麥克風能用，需要設定一次：Chrome 開 `chrome://flags` → 搜「insecure」→
「**Insecure origins treated as secure**」填入 `http://<電腦IP>:8080` → Enabled → Relaunch。
再用 Chrome 選單「加到主畫面」，桌面就有圖示。

## 五、常見問題 · FAQ

**Q：跑 install.ps1 說「缺少 python」或「不是內部或外部命令」**
Python 沒裝、或裝時忘了勾「Add to PATH」。重裝一次 Python 記得勾，**重開 PowerShell** 再跑。

**Q：`wsl --install` 失敗 / 沒反應**
確認是**系統管理員** PowerShell；Windows 要夠新（Win10 2004+ 或 Win11）。裝完**一定要重開機**。還不行就到「控制台 → 開啟或關閉 Windows 功能」勾「**適用於 Linux 的 Windows 子系統**」+「**虛擬機器平台**」，重開機。

**Q：install.ps1 說「看不到 GPU」**
到 GeForce 官網更新**顯卡驅動**到最新（支援 WSL）。或者改用 CPU 版：`install_cpu.ps1`。

**Q：能用，但聲音是「通用聲」不是家人的**
你還沒設音色 → 到 `/setup`「設定陪伴聲音」上傳家人錄音。或語音克隆（Qwen）還在載，等 1–2 分鐘。

**Q：平板按了按鈕沒反應 / 沒跳麥克風權限**
平板要跟電腦**同一個 WiFi**。用瀏覽器的話要做第四節的 `chrome://flags` 設定（用 App 就不用）。
麥克風權限是「**按住按鈕時**」才會跳，不是開網頁時。

**Q：下載卡很久**
正常。語音環境有 PyTorch + 模型好幾 GB，放著讓它跑完。
