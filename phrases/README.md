# 固定句快取（phrases）

爺爺常說的、重複性高的話，可以預先準備好回覆音檔，命中時**秒回**，
完全繞過 LLM（MiMo）和 TTS（CosyVoice）——零延遲、不依賴網路、最可靠。

## 怎麼用

1. 把回覆音檔（`.wav` 或 `.mp3`）放進這個 `phrases/` 資料夾。
   - **最推薦用家人真實錄音**（品質比克隆更好、最溫暖）。
   - 也可以用 CosyVoice / edge-tts 先合成好存起來。
2. 編輯 `phrases.json`，每條規則一個物件：
   - `triggers`：爺爺講的話**只要包含**其中任一字串就命中（子字串比對）。
   - `file`：要回播的音檔（相對於 `phrases/`）。
   - `text`：螢幕上顯示的回覆文字（也會寫進對話記憶）。
3. 重啟 `companion_web.py` 生效（啟動時會載入到記憶體）。

## 範例 phrases.json

```json
[
  {
    "triggers": ["吃藥", "吃药", "藥"],
    "file": "medicine.wav",
    "text": "爺爺，該吃藥囉，我陪你一起吃。"
  },
  {
    "triggers": ["你好", "早安", "哈囉", "在嗎"],
    "file": "greeting.wav",
    "text": "爺爺早安！今天有沒有睡飽呀？"
  },
  {
    "triggers": ["你是誰", "誰啊"],
    "file": "who.wav",
    "text": "我是你的孫子呀，永遠都在這裡陪爺爺。"
  }
]
```

## 注意

- **不要**把需要「當下資訊」的問題放進來（例如「現在幾點」「今天星期幾」），
  那些答案會變，必須走 LLM 動態產生。
- 比對是**第一條命中就用**，所以把比較具體的規則放前面。
- 缺音檔或缺 `triggers` 的規則啟動時會被略過（不會讓系統崩潰）。
